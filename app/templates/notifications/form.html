Help
Match modes
  • Every occurrence: each time the chosen (type, value) pair shows up in a new message, fire one delivery (with the message + channel + sender as context).
  • New occurrence: fire once the very first time the pair is matched, then go silent.
Value examples
  • URL → https://example.com/path or example.com for a domain entry
  • Hashtag → #crypto
  • @Mention → @alice
  • Phone → +61400000000
Targets
  • Webhook: HTTP POST with JSON body. Failures retry with exponential backoff.
  • RabbitMQ: published to the queue/exchange you specify on the broker the rest of Trawlr is already wired to.
